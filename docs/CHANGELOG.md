# 변경 기록

버전을 올릴 때(`npm version`)마다 맨 위에 그 버전의 변경 사항을 짧게 적습니다.
아직 버전을 올리지 않은 변경은 "다음 버전"에 모아 두었다가, 버전을 올릴 때 제목을 버전 번호와 날짜로 바꿉니다.

분류: **추가**(새 기능) · **변경**(동작이 달라짐) · **수정**(버그) · **내부**(사용자에게 보이지 않는 코드·문서 정리) · **서버**(운영 DB 에 실행할 SQL 이나 대시보드 설정)

---

## 0.5.7 (2026-11-12)

**변경**
- 앱 시작이 느린 회선에서도 빨라지도록
  - 로그인 상태 확인이 첫 화면을 막지 않음: 기기에 저장된 로그인 정보로 바로 시작하고, 만료된 로그인 갱신은 뒤에서 (갱신이 네트워크 오류로 실패해도 로그아웃되지 않음)
  - 첫 화면에 필요 없는 화면(운동·그룹·설정·관리자·약관 등)은 따로 받아 오고, 첫 화면이 뜬 뒤 미리 받아 둠. 첫 다운로드 147KB → 129KB(압축 기준)
  - React·Supabase 를 별도 파일로 분리: 앱 코드만 바뀐 배포 뒤에는 이 100KB 를 다시 받지 않고 캐시에서 씀
- 로딩 화면 안내를 늦추고 부드럽게: 5초 뒤 "조금 오래 걸리고 있어요…", 12초 뒤 다시 시도·오프라인 시작 버튼 (전에는 3초·8초)
- 비회원 그룹 탭 자물쇠 아이콘 가운데의 빨간 점을 없앰

## 0.5.2 (2026-11-12)

**변경**
- 서비스 이름 표기를 Absolid → ABSolid 로 변경 (앱 제목, 로고, 알림, 약관, 문서). GitHub 저장소 주소도 ABSolid 로
- 기능 소개 팝업의 진행 표시를 팝업 맨 위로 옮기고, 동그라미 점을 둥근 막대로 변경
- 디자인 점검 반영 (모바일 UI/UX 가이드 기준)
  - 운동 완료 팝업: 빛나는 체크, 연속 기록 숫자 올라가기, 3·7·14·21·30일 등 이정표 축하 문구. 홈으로 돌아오면 streak·완료 표시가 한 번 튀어나옴
  - 운동 화면: "30일 프로그램" 진행 막대와 지금까지 완주 횟수
  - 빨강은 주요 버튼·달성 표시에만: 오류·위험 동작은 별도 색(`danger`), 공지·리마인더 배너와 응원 버튼은 중립색
  - 작은 글자 버튼(응원, 차단·신고, 닫기, 뒤로, 하단 링크 등)의 터치 영역을 44px 이상으로
  - 글자 대비 개선: 흰 글자를 올리는 빨강 버튼은 조금 더 진한 빨강, 하단 "시작" 글자는 원 아래로, 영상 위 DAY 뱃지는 어두운 바탕
  - 글자 크기 10단계 → 6단계(12·14·16·22·30·64px), 굵기는 보통·굵게 위주(큰 숫자만 더 굵게), 간격은 4·8의 배수로 통일, 카드 안쪽 여백 24px
  - 입력칸 글자 16px: 아이폰에서 입력할 때 화면이 확대되지 않음
  - ✓ ✕ ▲▼ 글자 기호를 SVG 아이콘으로 통일
  - 로딩 중 회색 자리표시(스켈레톤), 그룹 없음·인증샷 없음·로그인 필요 화면에 그림 추가

**서버**
- 알림 제목 변경을 위해 `notify-cheer`, `send-reminders` 함수 재배포 (완료)

## 0.5.1 (2026-11-11)

**내부**
- 코드 리팩토링. 화면 동작은 그대로이고 구조만 정리했습니다.
  - `Settings.jsx`(948줄)를 `pages/settings/` 6개 파일로, `Group.jsx`(549줄)를 `pages/group/` 3개 파일로 나눔
  - 회원 기능 서버 통신을 `api.js` 한 곳으로 모음 (`admin.js` 는 관리자 전용만 남김)
  - 반복 코드를 공통 부품으로 통합: 사진 고르기(`PhotoPicker.jsx`), 비밀번호 본인 확인(`PasswordConfirm.jsx`), 데이터 불러오기(`useLoad.js`), 로그인 사용자 조회(`currentUserId`)
  - 가입 정보 임시 저장 코드 삭제 (v0.10 SQL 의 가입 트리거가 서버에서 저장하므로 불필요)
- 문서 추가: [API 명세](API.md), 변경 기록(이 파일)
- Prettier 도입: 코드 스타일 통일 (작은따옴표, 세미콜론 없음, 줄 길이 120). `npm run format` 으로 정리
- 쓰지 않는 SQL 삭제: `auto-admin.sql`, `photos-cleanup.sql`, `reset-delete-policies.sql` (이후 SQL 이 같은 내용을 포함)

**변경**
- 프로필 사진 오류 안내가 알림창(alert)에서 화면 아래 토스트로 바뀜
- 운동 기록 초기화의 비밀번호 확인 창을 바깥 영역을 눌러 닫을 수 있음
- 관리자 화면에서 목록을 불러오지 못하면 토스트 대신 해당 카드 안에 사유를 표시
