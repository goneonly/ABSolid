# 변경 기록

버전을 올릴 때(`npm version`)마다 맨 위에 그 버전의 변경 사항을 짧게 적습니다.
아직 버전을 올리지 않은 변경은 "다음 버전"에 모아 두었다가, 버전을 올릴 때 제목을 버전 번호와 날짜로 바꿉니다.

분류: **추가**(새 기능) · **변경**(동작이 달라짐) · **수정**(버그) · **내부**(사용자에게 보이지 않는 코드·문서 정리) · **서버**(운영 DB 에 실행할 SQL 이나 대시보드 설정)

---

## 다음 버전

**내부**
- 코드 리팩토링. 화면 동작은 그대로이고 구조만 정리했습니다.
  - `Settings.jsx`(948줄)를 `pages/settings/` 6개 파일로, `Group.jsx`(549줄)를 `pages/group/` 3개 파일로 나눔
  - 회원 기능 서버 통신을 `api.js` 한 곳으로 모음 (`admin.js` 는 관리자 전용만 남김)
  - 반복 코드를 공통 부품으로 통합: 사진 고르기(`PhotoPicker.jsx`), 비밀번호 본인 확인(`PasswordConfirm.jsx`), 데이터 불러오기(`useLoad.js`), 로그인 사용자 조회(`currentUserId`)
  - 가입 정보 임시 저장 코드 삭제 (v0.10 SQL 의 가입 트리거가 서버에서 저장하므로 불필요)
- 문서 추가: [API 명세](API.md), 변경 기록(이 파일)
- Prettier 도입: 코드 스타일 통일 (작은따옴표, 세미콜론 없음, 줄 길이 120). `npm run format` 으로 정리
- 쓰지 않는 SQL 삭제: `auto-admin.sql`, `photos-cleanup.sql`, `reset-delete-policies.sql` (이후 SQL 이 같은 내용을 포함)

**변경**
- 서비스 이름 표기를 Absolid → ABSolid 로 변경 (앱 제목, 로고, 알림, 약관, 문서). GitHub 저장소 주소도 ABSolid 로
- 프로필 사진 오류 안내가 알림창(alert)에서 화면 아래 토스트로 바뀜
- 운동 기록 초기화의 비밀번호 확인 창을 바깥 영역을 눌러 닫을 수 있음
- 관리자 화면에서 목록을 불러오지 못하면 토스트 대신 해당 카드 안에 사유를 표시

## 0.5.0 (2026-11-11)

**추가**
- 사용자 차단: 그룹 멤버·인증샷에서 차단, 설정에서 해제
- 이메일 인증 대응: 인증 메일 링크로 앱 복귀, 인증 메일 다시 보내기
