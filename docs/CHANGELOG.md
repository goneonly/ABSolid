# 변경 기록

버전을 올릴 때(`npm version`)마다 맨 위에 그 버전의 변경 사항을 짧게 적습니다.
아직 버전을 올리지 않은 변경은 "다음 버전"에 모아 두었다가, 버전을 올릴 때 제목을 버전 번호와 날짜로 바꿉니다.

분류: **추가**(새 기능), **변경**(동작이 달라짐), **수정**(버그), **내부**(사용자에게 보이지 않는 코드, 문서 정리), **서버**(운영 DB 에 실행할 SQL 이나 대시보드 설정)

---

## 0.6.1 (2026-11-12)

**추가**

**변경**
- 하단 시작 버튼의 빨간 그림자(번지는 그라데이션)를 없앰
- 하단 탭의 그룹, 홈, 설정 아이콘을 속이 찬 모양으로 바꾸고, 운동 장소의 "집에서"도 같은 집 아이콘으로, "헬스장에서"의 아령도 속이 찬 모양으로 통일 (공통 `HomeIcon`, 쓰지 않게 된 선 모양 아이콘 삭제)


- 화면 테마 기본값을 다크에서 시스템(휴대폰 설정 따름)으로

**수정**
- 홈 화면 앱 아이콘 가장자리에 보이던 검은 테두리: 아이콘을 네 모서리까지 빨간색으로 꽉 채움 (아이폰, 안드로이드 모두). `npm run icons` 로 다시 생성
- 360px 이하 좁은 휴대폰에서 가입, 로그인 캡차 상자가 입력칸 밖으로 삐져나가던 문제: 좁은 화면에서는 칸 폭에 맞게 비율 그대로 줄여 표시
- Vercel 배포 때 뜨던 Node.js 버전 경고: `engines` 를 `>=20.19` 에서 `24.x` 로 고정. 범위로 적으면 새 Node 주 버전이 나올 때 자동으로 올라가 빌드가 깨질 수 있고, 프로젝트 설정과 달라 경고가 남. 테스트 도구(Vitest 5)가 Node 20 을 지원하지 않아 기존 값도 틀렸음
- 로컬, CI, Vercel 의 Node 버전을 24 로 통일 (`.nvmrc` 추가, CI 는 이 파일을 읽음)

**변경**
- 화면 문구, 주석, 문서에서 가운뎃점과 화살표 기호를 걷어내고 자연스러운 문장으로 정리 (예: "이름과 전화번호 변경", "설정의 기타 메뉴"). 화면의 데이터 줄 구분자만 띄어 쓴 가운뎃점으로 유지

**내부**

- 같은 계정의 로그인 정보가 갱신될 때 화면들이 데이터를 다시 불러오지 않게 함 (앱을 켤 때 역할 확인, 기록 동기화, 그룹 목록이 2~3번씩 중복 요청되던 문제)
- 개발 도구 업그레이드로 보안 경고 0건: Vite 5에서 8로, Vitest 3에서 5로 (배포되는 앱 코드와는 무관한 도구). Node.js 20.19 이상 필요
- 외부 글꼴 CSS 에 무결성 해시(SRI) 적용, 글꼴 서버 미리 연결
- 인수인계 안내 문서 추가 (`docs/HANDOVER.md`), README 구조 갱신
- `npm run check`(커밋 전 한 번에 검사), `npm run splash` 추가. CI 에 코드 스타일 검사 추가
- 반복되던 꺾쇠 아이콘을 공통 부품으로, 밖에서 쓰지 않는 함수의 export 제거
- 탈퇴와 관리자 삭제가 같은 정리 코드를 씀 (`_shared/purgeUser.ts`). 사진 정리를 계정 삭제 뒤로 옮겨, 삭제가 실패했는데 사진만 지워지는 일이 없게 함

**서버**
- `admin-delete-user` 함수 새로 배포, `delete-account` 함수 재배포
- (선택) `v0.10-signup-profile.sql`, `v0.11-abuse-limits.sql` 다시 실행: 가입 오류와 그룹 참여 거절 문구가 새 표현으로 바뀜 (재실행 안전, 안 해도 동작은 같음)
